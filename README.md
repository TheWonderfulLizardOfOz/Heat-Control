# Heat-Control
Arduino application allowing me to see the current temperature on display, set a target temp (to do), and control my heating.

## Why?
My flat does not have a temperature controlled gas boiler instead there is a button to turn the boiler on for an hour, and a really hard to use calendar. So instead I have developed this to control my heating using Arduino to physically push the button (I would take the button apart and 'push' by sending a signal, but I don't want to lose my deposit). 

Do I need a better landlord? Yes

## Pushing the button?
I started with using a servo to push the button, unfortunately it was very unstable and would fall apart quickly. Next step I will try a push pull solenoid, but it has not yet arrived
